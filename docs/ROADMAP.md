# Дорожная карта

## Уже реализовано

Базовый продукт:

- offline-first PWA;
- Web Components с Shadow DOM;
- IndexedDB persistence;
- экспорт/импорт `.prodnote.json`;
- задачи;
- проекты;
- теги;
- заметки;
- таймер;
- помодоро;
- ручные сессии;
- календарь;
- статистика;
- настройки.
- optional self-host server sync;
- passkey/WebAuthn вход без личных данных.

## Ближайшие улучшения

### Полный CRUD

Сейчас создание и часть удаления уже есть, но редактирование покрыто не полностью.

Нужно добавить:

- редактирование проектов;
- редактирование тегов;
- редактирование задач;
- удаление задач;
- удаление заметок;
- удаление тегов с безопасным снятием связей.

### Улучшение задач

Полезные следующие шаги:

- поиск и фильтры;
- сортировка по дедлайну, приоритету, проекту и времени;
- отдельная страница задачи;
- более удобный журнал;
- оценка времени и сравнение план/факт;
- быстрый запуск таймера прямо из карточки.

### Улучшение заметок

Следующие шаги:

- поиск по Markdown;
- связь заметки с несколькими задачами через UI;
- pinned notes;
- шаблоны заметок.

### Улучшение календаря

Следующие шаги:

- недельный/месячный вид;
- drag-and-drop планов;
- быстрый старт фокуса из календаря;
- визуальное сравнение план/факт;
- фильтр по проекту.

### Улучшение статистики

Следующие шаги:

- сравнение недель;
- тренды;
- productive streaks;
- план/факт по задачам;
- экспорт статистики;
- график фокус/перерыв для помодоро.

### Data migrations

Перед серьезным развитием модели данных нужно добавить миграционный слой:

- чтение старых `schemaVersion`;
- миграции по версиям;
- тестовые fixtures старых экспортов;
- user-facing сообщение при неподдерживаемой версии.

## Не входит в ближайшую область

Пока не планируется без отдельного решения:

- совместная работа;
- end-to-end encryption;
- мобильные native apps.

Эти функции сильно меняют архитектуру и должны проектироваться отдельно.
