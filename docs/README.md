# Документация ProdNote

ProdNote - offline-first PWA-приложение для задач, заметок, учета времени, помодоро, календаря и статистики. Приложение может работать без сервера: данные хранятся в IndexedDB браузера и могут экспортироваться в один `.prodnote.json` файл. Дополнительно доступен self-host сервер синхронизации на Node.js + PostgreSQL.

## Текущий статус

В проекте уже реализованы:

- задачи с канбаном и списком, приоритетами, дедлайнами, подзадачами и журналом;
- повторяющиеся задачи и быстрый ввод на естественном языке;
- умные списки, фильтры, поиск и массовые действия по задачам;
- проекты и теги;
- заметки в Markdown с preview, wiki-ссылками, бэклинками и историей сохранений;
- планер дня: чек-лист, серия дней, мастера планирования и закрытия дня;
- привычки и рутина с 28-дневной сеткой и сериями;
- обычный таймер, ручные сессии и помодоро;
- календарь (повестка/неделя/месяц), события, дедлайны, импорт/экспорт и подписки ICS;
- статистика по времени, задачам, проектам, тегам и часам, ревью недели;
- палитра команд (`⌘K` / `Ctrl+K`);
- напоминания и уведомления, опциональный Web Push;
- локальное хранение в IndexedDB и почасовые автобэкапы;
- экспорт и импорт `.prodnote.json`;
- PWA manifest и service worker;
- optional server sync через Node.js, Hono, PostgreSQL и passkey;
- native Web Components с Shadow DOM.

## Основные ограничения

- Сервер синхронизации optional; локальный IndexedDB остается рабочим источником для UI.
- Схема данных версионируется (текущая — `v17`); миграции применяются при загрузке и импорте.
- Offline-first поведение зависит от того, что приложение хотя бы один раз было открыто в браузере и service worker успел закэшировать shell.
